# Личный учёт 2026 — версия для айфона

Это не приложение из App Store, а веб-приложение: страница, которая после
установки на экран «Домой» ведёт себя как обычное приложение — своя иконка,
запуск на весь экран без адресной строки Safari, работа без интернета.

## Что внутри

    index.html              сам трекер
    manifest.webmanifest    имя, иконка, режим запуска
    sw.js                   офлайн-кэш
    icon-180/192/512.png    иконки

## Как опубликовать (10 минут, бесплатно)

Файлы должны лежать на адресе с https — иначе iOS не даст установить
приложение на экран «Домой». Самый простой способ — GitHub Pages.

1. Заведите аккаунт на github.com, если его нет.
2. Создайте репозиторий: кнопка «New», имя например `uchet`,
   тип **Private** — тогда сами файлы никто не увидит.
   Для Pages на приватном репозитории нужен платный план; если его нет,
   делайте **Public**, но тогда цифры окажутся в открытом доступе — см.
   раздел «Про приватность» ниже.
3. На странице репозитория: «Add file» → «Upload files» → перетащите все
   шесть файлов → «Commit changes».
4. «Settings» → слева «Pages» → в разделе «Build and deployment»
   выберите Source: «Deploy from a branch», Branch: `main`, папка `/ (root)`
   → «Save».
5. Через 1–2 минуты там же появится адрес вида
   `https://ваш-логин.github.io/uchet/`. Это и есть ссылка на приложение.

Альтернативы, если GitHub не нравится: netlify.com (перетащить папку в окно
Netlify Drop — адрес выдаётся сразу, приватность та же), любой хостинг с https.

## Как поставить на айфон

1. Откройте адрес **в Safari** (в Chrome установка на «Домой» не работает).
2. Кнопка «Поделиться» внизу → «На экран «Домой».
3. Имя по умолчанию — «Учёт», можно поменять.
4. Запускайте с иконки. Адресной строки не будет, интернет не нужен.

## Про данные — важное

Цифры хранятся в памяти браузера на этом айфоне, а не в файле и не на сервере.
Из этого следует:

- На компьютере и на телефоне будут **разные** данные, они не синхронизируются.
- Удаление приложения с экрана «Домой» стирает и данные.
- Переустановка iOS, очистка данных Safari — то же самое.

Поэтому раз в месяц, когда вносите новые остатки, заходите во вкладку
«Анализ» → «Выгрузить / загрузить данные» → **Скачать файл** и кладите json
в iCloud. Это единственная копия. Перенос между устройствами — тем же файлом,
через «Загрузить файл».

## Про приватность

На публичном репозитории GitHub Pages файлы доступны любому, кто знает адрес,
и их индексируют поисковики. В `index.html` зашиты ваши суммы по счетам —
они станут видны. Варианты: платный план GitHub с приватными Pages,
либо перед публикацией обнулить стартовые данные в коде (константы
`ACCOUNTS`, `SEED_INCOME`, `YEARS_SEED`, `PATCH` в начале скрипта),
а свои цифры залить уже на телефоне через «Загрузить файл».

## Как обновлять

Заменили `index.html` — обязательно поднимите версию в `sw.js`:
строка `const VERSION = "uchet-2026-v1"` → `v2`. Иначе айфон продолжит
показывать старую копию из кэша.
